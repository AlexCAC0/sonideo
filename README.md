# Sonideo - Neo Edition

Sonideo es un juego web interactivo diseñado para poner a prueba tus conocimientos musicales. Esta edición especial "Neo" presenta una estética moderna y una selección curada de éxitos del pop y reggaetón en español de los años 2000.

## ✨ Novedades del Diseño
El proyecto ha sido actualizado con una identidad visual **Neo-Grotesk Glass**:
- **Estética Glassmorphism**: Interfaces translúcidas con efectos de desenfoque de fondo y bordes brillantes.
- **Fondo Dinámico**: Fondos con gradientes de malla animados que le dan vida a la experiencia.
- **Podio 3D Refinado**: Un sistema de visualización de ganadores con animaciones de entrada "Pop-In", efectos de flotación y brillo dinámico.
- **Feedback Visual y Sonoro**: Sistema sutil de viñetas (Verde/Rojo) para aciertos y errores, con audio optimizado para una experiencia no invasiva.

## 🚀 Tecnologías
- **Vite**: Para un desarrollo rápido y optimizado.
- **Firebase**: Sincronización en tiempo real para el estado del juego, estadísticas y reproducción.
- **Vanilla CSS**: Estilo a medida siguiendo los principios de diseño moderno.
