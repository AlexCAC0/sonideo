# Project Context: Sonideo - Temporada 2 (T2: Neo Soundwave Edition)

"Sonideo" is a real-time web-based music trivia game powered by Firebase Realtime Database and Vite.

## Technical Stack & Environment
*   **Development Server:** Vite (`npm run dev`).
*   **Firebase Integration:** Real-time database for game state, player buzzes, stats, and audio playback synchronization.

## Visual Identity: T2 - Neo Soundwave Edition
*   **Branding:** Official Temporada 2 (T2) badges, "Neo Soundwave" aesthetic.
*   **Design System:** Glassmorphism with animated radial mesh background, soundwave equalizer visual elements, responsive glass cards, and neon accents.
*   **Feedback System:** Green/Red edge vignette and subtle audio cues (0.05 - 0.08 volume).
*   **Podium & Leaderboards:** 3D animated podium with Pop-In entry, floating crown 👑 for 1st place, live temporary leaderboard overlay, and detailed expandable post-game stats (Correct, Incorrect, Success Rate %).
